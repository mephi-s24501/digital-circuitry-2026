**Этот документ описывает работу OLED-дисплея.**

### Распиновка

Интересные пины (Figure 7-1):

- `BS[2:0]` выбор интерфейса. *Установить в `010` для выбора I²C* (Table 7-1)
- `RES#` сброс
- `CS#` chip select
- `D/C#` выбор Data/Command. *В I²C режиме — `SA0` (выбор адреса)*
- `D0` - SCL
- `D[1:2]` - SDA (замкнуть вместе)
- `D[3:7]`, `R/W#`, `E` на землю

`SA0` установить в 0 для выбора адреса 0111100. Других слейвов на шине нет.

Раздел 8.1.5.1 описывает работу в I2C режиме.

### Тайминги

Частота SCL ≤ 400 кГц. Эту частоту задать как Generic DISPLAY_CLOCK_G.
